# 쇼다운 모아보기

IBSA 쇼다운 관련 자료의 기본정보와 원문 링크를 제공하는 정적 웹 앱입니다.

서비스 주소: https://ajackpot.github.io/showdown-hub/

앱 버전: 0.6.1. 승인 자료 5건을 제공합니다. 자료별 원출처와 날짜를 확인하세요. 인터넷 전체 자료를 빠짐없이 수집한다고 보장하지 않습니다.

공개 화면의 **목록 다시 불러오기**는 이미 배포한 자료만 다시 읽습니다. 외부 사이트 수집과 자료 검토는 운영자의 별도 PC 도구에서 수행합니다.

이 저장소에는 공개 배포 파일과 이 안내만 포함합니다. 운영 저장소·내부 검토 기록·인증 정보는 포함하지 않습니다. 자료의 본문·이미지·첨부에 대한 권리는 원발행처의 조건을 따릅니다.

키보드·자동 접근성 검사를 수행했습니다. 실제 NVDA·확대·고대비·모바일 보조기술 검증은 배포 후 별도 세션에서 진행하며, 접근성 적합성 완료를 주장하지 않습니다.

재배포할 때는 운영자 도구에서 만든 새 ZIP의 8개 파일을 같은 커밋으로 교체합니다. 코드와 자료를 서로 다른 버전으로 섞지 않습니다. 파일 구성과 SHA-256은 `release.json`에서 확인합니다.
